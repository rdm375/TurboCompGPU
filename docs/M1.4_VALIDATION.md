# M1.4 — Nonlinear Compressor Solver Validation

**Project:** TurboCompGPU
**Milestone:** M1.4
**Date:** 2026-10-11
**Status:** Numerical validation and CPU performance benchmarking complete

## 1. Overview

M1.4 establishes a validated CPU reference implementation for
centrifugal compressor operating-point calculations using ThermoGPU 2.0.

The implementation combines real-gas thermodynamics, impeller meanline
aerodynamics, conservation equations, entropy-generation closures,
nonlinear Newton solving, and independent physical validation.

GPU acceleration remains a future development objective.

## 2. Nonlinear formulation

The solver determines outlet temperature and pressure using two
normalized nonlinear residuals:

- Energy closure.
- Entropy closure.

The unknowns are outlet temperature and logarithmic outlet pressure.

The shared Newton implementation provides dimensionless coordinates,
finite-difference Jacobians, central and one-sided differencing,
singular-Jacobian detection, Armijo backtracking, and explicit
termination diagnostics.

## 3. Optimized residual evaluation

The optimized formulation caches inlet thermodynamic information
and evaluates the outlet state directly.

This avoids repeated reconstruction of the complete impeller system
during Newton iterations.

Independent five-residual validation remains available.

### Thermodynamic property evaluations

| Model | Full calls | Fast calls | Reduction |
|---|---:|---:|---:|
| Ideal gas | 848 | 17 | 49.88x |
| Peng–Robinson | 1407 | 22 | 63.95x |

These are property-call reductions, not wall-clock speedups.

## 4. Type safety

The shared Newton implementation supports distinct residual-result
types.

The optimized residual evaluator returns its own result type without
requiring the complete physical-system result.

Compile-time regression tests verify the intended type relationships.

## 5. Thermodynamic reference invariance

The optimized solver was tested against independent enthalpy and
entropy reference shifts.

Results:

- Shifted solves: 54.
- Unshifted baselines: 6.
- Changed iteration counts: 0.
- Maximum outlet temperature difference: 1.7053e-13 K.
- Maximum outlet pressure difference: 3.6089e-09 Pa.
- Maximum specific-work difference: 3.6380e-11 J/kg.
- Maximum torque difference: 1.4211e-13 Nm.

All shifted cases passed.

## 9. Wall-clock performance

Three execution modes were benchmarked:

- Full nonlinear solver.
- Optimized solver with fresh context construction.
- Optimized solver with independent physical validation.

Each operating condition used 1000 timed repetitions after warm-up.

## 11. Reproducibility

Configure:

    cmake -S . -B build-cpu \
        -DCMAKE_BUILD_TYPE=Release \
        -DCMAKE_PREFIX_PATH=/path/to/ThermoGPU/install

Build:

    cmake --build build-cpu -j2

Test:

    ctest --test-dir build-cpu --output-on-failure

Benchmark:

    ./build-cpu/turbocompgpu_nonlinear_wall_clock \
        benchmarks/results-wall-clock/timings.csv 1000 100

Analyze:

    python benchmarks/analyze_wall_clock.py \
        benchmarks/results-wall-clock/timings.csv

Raw data, analysis scripts, and convergence-basin plots are
retained under `benchmarks/`.

## 12. Limitations

M1.4 does not establish:

- Global nonlinear convergence.
- Validity across arbitrary compressor geometries.
- Surge or choke boundary predictions.
- Complete compressor performance maps.
- GPU or OpenMP acceleration.
- Performance portability across hardware.
- Independent experimental validation against measured compressors.

Results apply to the tested models, geometry, operating conditions,
and initial guesses.

Timing distributions show system-level variability. More tightly
controlled experiments would be needed for precise cross-platform
performance comparisons.

## 13. Conclusion

M1.4 establishes a validated CPU reference solver for centrifugal
compressor operating-point calculations.

The optimized formulation preserves the tested physical and
numerical behavior while reducing median execution time by
approximately:

- 48–61x for nonlinear solving.
- 12–16x including independent physical validation.
