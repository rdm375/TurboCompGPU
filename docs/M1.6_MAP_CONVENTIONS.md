# M1.6 Compressor-Map Conventions

## Reference conditions

Corrected coordinates use explicit user-supplied reference
temperature and pressure.

No universal reference conditions are assumed.

## Corrected coordinates

Let

    tau   = Tt1 / Tref
    delta = pt1 / pref

Then

    corrected_mass_flow = mass_flow * sqrt(tau) / delta

    corrected_speed = rotational_speed / sqrt(tau)

These are conventional ideal-gas-style corrected coordinates.

They are not guaranteed to provide similarity collapse for
real-gas mixtures or changing gas composition.

## Thermodynamic station conventions

The existing nonlinear operating-point API uses inlet and
outlet thermodynamic temperature and pressure.

The full compressor residual also evaluates stagnation
enthalpy.

These facts do not establish that the operating-point
pressure ratio is total-to-total.

Pressure-ratio conventions must therefore be explicit.

## Efficiency conventions

M1.6a does not calculate efficiency.

Future isentropic and polytropic efficiency implementations
must state their thermodynamic paths and reference states.

For real-gas models, the isentropic outlet state should be
obtained from the EOS rather than inferred using a fixed
ideal-gas heat-capacity ratio.

## Operating limits

Surge and choke limits remain NotEvaluated.

Numerical convergence does not imply aerodynamic
admissibility.

M1.6a tests verify:

- Temperature scaling.
- Pressure scaling.
- Explicit pressure-ratio conventions.
- Invalid-input rejection.
