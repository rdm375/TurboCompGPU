# M1.5 Operating-Envelope Validation

## Scope

Deterministic mass-flow and rotational-speed sweeps
using the M1.4 nonlinear compressor solver.

Models: IdealGas and PengRobinson.

Mass flows: 2, 3, 4, 5, 6, 7, 8 kg/s.

Rotational speeds: 9000, 10500, 12000, 13500, 15000 rpm.

Fixed inlet: 300 K, 500000 Pa.

Prescribed entropy generation: 20 J/(kg K).

## Numerical validation

- Distinct operating conditions: 70.
- Total nonlinear solves: 140.
- Converged: 140/140.
- Independently validated: 140/140.
- Basic physical checks: 140/140.
- Surge/choke limits: NotEvaluated.

## Physical interpretation

All tested points satisfy the implemented positive-pressure-rise,
positive-work, positive-density, and power/torque checks.

These checks do not establish aerodynamic admissibility.
Surge and choke boundaries are not predicted by the current model.

Entropy generation is prescribed, not calculated from a
flow-dependent aerodynamic loss correlation.

The IdealGas and PengRobinson configurations should not be
interpreted as a controlled real-gas comparison without
matching caloric and reference-property conventions.
